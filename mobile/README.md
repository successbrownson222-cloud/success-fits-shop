# Success Fits Mobile

Live API: https://success-fits-shop.vercel.app
Web Live: https://success-fits-shop.vercel.app

This mobile app syncs cart with web using same email.

## How to run
- Open https://snack.expo.dev
- Import App.js
- Run on Expo Go

## Features
- Login with same email as web
- Same cart (cart sync)
- Filter by Shoes/Clothes/Jewelry/Accessories
- Add to cart + clear cart
